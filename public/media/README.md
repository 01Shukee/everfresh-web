# Media library structure
Drop genuine Everfresh files here and register them in `src/content/home.ts` (and later in the database/media library).
- food/      menu and dish photos
- training/  workshop, facility and training photos
- projects/  completed student projects
- catering/  genuine event and catering photos
- video/     training and showcase videos (with captions .vtt and a poster image)
Rules: real Everfresh media only; descriptive alt text; no stock or generated images presented as the business.
